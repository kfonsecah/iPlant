    Create `src/services/storageService.ts` to provide high-level wrappers for `AsyncStorage` and `expo-file-system`.
    
    1. **Data Storage (AsyncStorage):**
       - `saveItem<T>(key: string, value: T): Promise<void>`: JSON.stringify and save.
       - `getItem<T>(key: string): Promise<T | null>`: Retrieve and JSON.parse.
       - `removeItem(key: string): Promise<void>`.
    2. **Image Storage (FileSystem):**
       - `persistImage(tempUri: string): Promise<string>`:
         - Generate a unique filename using `Date.now()` or `expo-crypto.randomUUID`.
         - Move file from `tempUri` to `FileSystem.documentDirectory` + `images/` folder.
         - Ensure the directory exists using `FileSystem.makeDirectoryAsync`.
         - Return the new permanent URI.
  </action>

  </verify>
