    2. Extraer `getPermission` del hook: `const [permission, requestPermission, getPermission] = useCameraPermissions();`.

       ```typescript

         const subscription = AppState.addEventListener('change', nextAppState => {

             getPermission();
           }
         });
         return () => subscription.remove();
       }, [getPermission]);
       ```
